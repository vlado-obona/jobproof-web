# jobproof-web

Verejný web aplikácie **JobProof** (BEDEKA, s.r.o.) na GitHub Pages → <https://vlado-obona.github.io/jobproof-web/>

| Stránka | Účel |
|---|---|
| `/` | úvod, nábor do pilotu |
| `/sukromie/` | zásady ochrany súkromia – URL pre Google Play |
| `/zmazanie-uctu/` | postup zmazania účtu a údajov – URL pre Google Play (Data safety) |
| `/vop/` | podmienky pilotnej prevádzky vrátane zmluvy o spracúvaní osobných údajov |

Čisté HTML + `assets/style.css`, bez buildu a bez sledovacích skriptov. Nasadenie: `.github/workflows/pages.yml` pri každom pushi na `main`.

**Raz treba zapnúť:** Settings → Pages → Build and deployment → Source = **GitHub Actions**.

Texty právnych stránok sú **návrhy** – pred pilotom ich schvaľuje Vlado (ideálne s právnikom); hranaté zátvorky `[ ]` označujú údaje na doplnenie.

Aplikácia a zadanie: súkromné repo `vlado-obona/jobproof` (`docs/handoff/HANDOFF.md`).
